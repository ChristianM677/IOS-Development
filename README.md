## BMI Calculator

This is a pretty straightforward app which takes your height and weight to calculate the BMI. The basics of this app include sliders which allow to slide to your weight and height and then when pressing the calculate button your met with another screen which shows the results and a useful note.

## ByteCoin

This is a simple app in which theirs a spinning wheel that includes different world currencies and clicking on one currency it will give you the real time price for 1 Bitcoin and this grabs the real time price using an API website. 

## Clima

This app is a weather app that catches the real time weather data using an API website called OpenWeather. Its pretty straightforward where you can search for a city and it will give you the weather with its icon.
